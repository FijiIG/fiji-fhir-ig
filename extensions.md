## Extensions

### Extensions

These optional extensions for Fiji Patient profile are defined in this implementation guide.

* [Fiji iTaukei Affiliation](StructureDefinition-fiji-iTaukei-affiliation.md) - Optionally used to record Yasana, Korodina, Tikina, Yavusa, Mataqali and Tokatoka affiliation
* [Patient Occupation](StructureDefinition-fiji-patient-occupation.md) - Optionally used to record patient occupation
* [Patient Ethnicity](StructureDefinition-fiji-patient-ethnicity.md) - Used to record patient ethnicity
* [Birth Date Verified](StructureDefinition-birthdate-verified-indicator.md) - Used to indicate if a patient birthdate has been officially verified

These HL7 commonly used extensions are also added to the Fiji Patient profile:

* [Patient Nationality](https://hl7.org/fhir/extensions/5.4.0/en/StructureDefinition-patient-nationality)
* [Patient Religious Affiliation](https://hl7.org/fhir/extensions/5.4.0/en/StructureDefinition-patient-religion)
