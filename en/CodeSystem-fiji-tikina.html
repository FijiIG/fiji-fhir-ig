CodeSystem: Fiji Tikina

Official URL: https://fhir.health.gov.fj/CodeSystem/fiji-tikina Version: 0.3.0
Active as of 2026-10-23 Computable Name: FijiTikinaCS

Copyright/Legal: Distributed under the Creative Commons CC0-1.0 License (https://creativecommons.org/publicdomain/zero/1.0/)

A code system representing the tikina (districts) of Fiji for use in healthcare information exchange.

Codes are based on the Fiji geographic coding convention and should be validated against the adopted authoritative geographic dataset.

Tikina are associated with their respective provinces.

This Code system is referenced in the definition of the following value sets:

  • Fiji Tikina ValueSet
  • Fiji Yasana ValueSet
