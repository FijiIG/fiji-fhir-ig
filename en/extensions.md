# Extensions - Draft Fiji Core Implementation Guide v0.9.0

## Extensions

### Extensions

This page describes lists extensions used in the implementation guide.

#### Extensions used for Patient

The following optional extensions are defined for Fiji Patient profile:

[Fiji iTaukei Affiliation](StructureDefinition-fiji-iTaukei-affiliation) [Patient Occupation](StructureDefinition-fiji-patient-occupation) [Patient Ethnicity](StructureDefinition-fiji-patient-ethnicity) [Birth Date Verified](StructureDefinition-birthdate-verified-indicator)

These HL7 commonly used extensions are also added to the Fiji Patient profile: [Patient Nationality](https://hl7.org/fhir/extensions/5.4.0/en/StructureDefinition-patient-nationality) [Patient Religious Affiliation](https://hl7.org/fhir/extensions/5.4.0/en/StructureDefinition-patient-religion)
