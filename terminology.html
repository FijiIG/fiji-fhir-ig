Terminology

This page describes the code systems and valuesets that are defined in this Implementation Guide.

SNOMED CT for Clinical Terminology

In order to facilitate future interoperability both internally within Fiji and between other nations in the region, Fiji MHMS has made a strategic decision to adopt the SNOMED CT (International) clinical terminology as the primary representation of coded clinical concepts for this FHIR Implementation Guide. Current Fiji MHMS systems at the time of publishing of this Implementation Guide do not yet support SNOMED CT and thus legacy data is either uncoded or used alternate terminology sets. However, future application acquisitions, upgrades and deployments should support this strategic intent.

Historic clinical records and legacy data may use alternative terminologies or local coding systems and valuesets for coded entries, but wherever possible, current systems should migrate towards the use of SNOMED CT for coded data.

Free text entry should only be permitted for Codeable Concepts if no suitable coded value is available, or in order to retain uncoded free text historic information.

Use of Full SNOMED refsets

After discussion on the relative merits of using full SNOMED refsets vs the International Patient Summary curated subsets, it was decided (23/10/2026 at Sydney workshop) to use the full refsets in the Valuesets of this Implementation Guide.

Other International Terminology Sets Used

The following terminologies are used for specific profiles/elements in this implementation guide.

  • CVX Standard Code Set for Vaccines These codes are used in the valueset bound to the Immunization profile vaccineCode element.
  • ATC Anatomical Therapeutic Chemical Code Set These codes may be used in the Medication Value Set used in MedicationRequest and MedicationDispense profiles for the medication element.
  • ICD-10 AM These codes are included to support legacy data handling, and may be used in the Condition (Diagnosis) or Medication Request Reason valuesets.

ValueSets

The following table lists the ValueSets defined in the Fiji Core Implementation Guide. Note that other ValueSets defined as a part of the HL7 FHIR R4 are used as defined in the specification.

ValueSet Name Description
Allergy Causative Agent Value Set A subset of SNOMED CT concepts representing substances or products that cause allergies or intolerances.
Body Position Value Set SELECT SNOMED CT code system values the position in which the individual was in during a measurement.
Body Site Value Set Valueset for bodysite/anatomical structures. Used for Condition.bodySite and Immunization.site Values from SNOMED CT anatomical structures.
Body Weight Vital Value Set Concepts representing options that provide further context for body weight coding. (eg. Birth Weight…) NOTE: This is not currently used but may be used in future when a full valueset has been developed
Condition (Diagnosis) Value Set Condition Code valueset for Fiji Core. Includes "clinical finding" codes and codes for "situation with explicit content".
Condition Evidence Value Set Evidence: Signs, symptoms, procedures, and labs, explicitly excluding formal diseases.
Dicom Modality Value Set Imaging acquisition modalities based on DICOM CID 29.
Encounter Reason Value Set Encounter reason valueset for Fiji Core. Proposed valueset is taken from SNOMED descendant of clinical findings and Procedures.
Fiji Patient Ethnicity ValueSet The set of ethnicity codes recognised by the Fiji Implementation Guide
Fiji Korodina Value Set The set of korodina codes recognised by the Fiji Implementation Guide.
Fiji Mataqali Value Set Mataqali codes recognised by the Fiji Implementation Guide.

Immunization Value Set Immunization valueset based on until Fiji-Pacific valueset is developed
Medication Request Reason Value Set MedicationRequest reason valueset for Fiji Core. Proposed valueset is taken from SNOMED Problem/Diagnosis refsets.

Code System Name Description

Fiji Occupation CodeSystem A code system representing patient occupation in Fiji for use in healthcare information exchange. Codes and display names should be sourced from the authoritative Fiji geographic administrative dataset adopted by the Fiji Implementation Guide.

Fiji MSupply Medication CodeSystem A code system representing legacy MSupply medication codes used in Fiji, for use in healthcare information exchange with legacy medication dispense information and until a standardised codesystem for medications is agreed. Codes and display names should be sourced from the MSupply codes used in Fiji for dispensing medication.
Fiji Mataqali CodeSystem A code system representing mataqali recognised in Fiji, for use in healthcare information exchange where identification of a mataqali is required. Fiji Tikina CodeSystem A code system representing the tikina (districts) of Fiji for use in healthcare information exchange. Codes and display names should be sourced from the authoritative Fiji geographic administrative dataset adopted by the Fiji Implementation Guide.

Fiji Yasana CodeSystem A code system representing Yasana (province) largest administrative division codes in Fiji iTaukei society as recognised in Fiji. Codes and display names should be sourced from the authoritative Fiji geographic administrative dataset adopted by the Fiji Implementation Guide.
Fiji Yavusa CodeSystem A code system representing Yavusa in Fiji for use in healthcare information exchange. Codes and display names should be sourced from the authoritative Fiji geographic administrative dataset adopted by the Fiji Implementation Guide.
